## [0.21.01-1] - 2026-09-26

Initial release — `stress-ng` 0.21.01 as a single self-contained binary, built
natively for Linux and macOS.

### Added

- Builds for Linux (x86_64, aarch64, armv7l, i686, ppc64le, riscv64) and macOS
  (x86_64, aarch64).
- `stress-ng.1` man page embedded in the binary — read it with `unpin man stress-ng`.
